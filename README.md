# Tote Bags Canada — B2B Wholesale & Custom Manufacturing Website

Official B2B website repository for **Tote Bags Canada** (Project ID: `PRJ-001 / CCT-01`), built for client **Mr. Wasi** and managed under **SYNNC. Product & Engineering**.

---

## 📌 Project Overview
A focused, high-converting B2B wholesale platform designed for one core product family: **Tote Bags**.
* **Target Audience:** Canadian businesses, corporate procurement, promotional merchandise agencies, retailers, and event organizers.
* **Primary Conversion:** Request a Wholesale Quote (RFQ) — no consumer shopping cart or retail checkout.
* **Official Domain:** `totebagscanada.com`
* **Direct Sales Desk:** `sales@totebagscanada.com` | `+1 (236) 513-9254`

---

## 🚀 Key Features

* **Prominent Brand Identity:** Features the official brand logo (`images/logo.png`) and exact brand green (`#346337`).
* **Curated 8-Product Showcase:** Real sample photographs representing our core bag constructions:
  1. *Contrast Heavy Boat Tote* (Signature 16oz–18oz canvas, ~53cm width)
  2. *Custom Sized Canvas Totes* (Small, Medium, Large, Extra-Large)
  3. *Artisan Embroidered Edition* (High-thread-count custom monogramming & floral zipper trim)
  4. *Wholesale Blank Totes* (Unprinted blanks in 4 standard sizes)
  5. *Everyday Promo Cotton* (Natural, White, and Black promo flats)
  6. *Appliqué & Patch Tote* (Brass hardware & custom patches)
  7. *The Eco Jute Tote* (Natural burlap with vegan leather handles)
  8. *Full-Color Graphic Canvas* (Digital full-color edge-to-edge printing)
* **Dual Order Pathways:**
  * **Route 1:** Custom Artwork / Bespoke Manufacturing (Upload client logo/vector)
  * **Route 2:** Shown Designs & Blank Wholesale Stock
* **Integrated Wholesale RFQ Engine:**
  * Preset quick quantity chips (`25`, `100`, `500`, `1,000`, `5,000`, `10,000+`) plus custom numeric input.
  * Required fields: Full Name, Business Email, Company, Country / Province, Quantity, and Requirement Description.
  * Optional fields: Phone number, Target Delivery Date, City / Postal Code, and Artwork Upload (PDF, AI, EPS, SVG, PNG up to 25MB).
  * Interactive *"Quote This Model"* buttons that auto-scroll and pre-populate the selected bag style into the form.
* **100% Mobile & Desktop Responsive:** Optimized using modern responsive layouts, accessible typography, and smooth scrolling.

---

## 🛠️ Technology Stack
* **Markup:** Semantic HTML5
* **Styling:** Tailwind CSS (via optimized CDN with customized brand color palette)
* **Typography:** Plus Jakarta Sans (Google Fonts)
* **Interactions:** Vanilla JavaScript (Mobile menu drawer, dynamic quantity chips, form validation, and instant confirmation state)

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Minahil2117/Tote-Bags-Canada.git
   ```
2. Navigate into the folder:
   ```bash
   cd Tote-Bags-Canada
   ```
3. Open `index.html` directly in your browser, or launch it with VS Code's **Live Server** extension:
   * Right-click `index.html` ➔ **Open with Live Server**.
